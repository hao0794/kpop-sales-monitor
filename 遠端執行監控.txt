遠端執行監控

最簡單的方式是直接用 iPhone／iPad 的「銷量監控」捷徑，以下是用 Termius 手動操作的方法。

登入 Tailscale、Termius
進入資料夾並啟用環境
cd ~/Documents/sales_monitor
source .venv/bin/activate

在背景啟動監控
python sales_monitor.py sc start
顯示「🟢 監控已啟動」就成功了，之後關掉 Termius、手機鎖螢幕都不影響。
（舊的寫法 nohup caffeinate -i python sales_monitor.py run > run.log 2>&1 & 也能用，但建議改用這行）

確認監控有在跑
python sales_monitor.py sc status
第一行顯示「🟢 執行中」就代表正在執行，下面還會列出每個商品的總銷量和剩餘庫存。

即時查看監控紀錄
tail -f monitor.log
按 Control + C 離開查看，監控不會被停止。

停止監控
python sales_monitor.py sc stop

同時只能有一個監控在跑，程式會自動檢查：如果已經在執行中（不論是從 Mac 終端機、捷徑或 Termius 啟動的），再啟動一次只會顯示「監控已經在執行中」，不會重複執行。

新增商品（監控執行中也可以）
python sales_monitor.py add "商品網址"

修改 config.json
nano config.json
用方向鍵移動游標修改內容。改完按 Control + O 再按 Enter 存檔，最後按 Control + X 離開。Termius 鍵盤上方的工具列有 Ctrl 鍵可以用。
大部分設定也可以用捷徑的「⚙️ 修改設定」修改，不用自己編輯 JSON，比較不會改壞格式。
