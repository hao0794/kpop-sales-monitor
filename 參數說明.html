自定義數據

config.json 裡的 "default": { "interval_minutes": 5 } 就是預設頻率，改數字即可（支援小數，例如 0.5 = 30 秒）；schedules 裡的特定時段也是用分鐘設定

排名依購買量由多到少，筆數由 ranking_count 控制，想改成 50 或 100 直接改數字。數量相同時，較早購買的排前面。

放很多商品但暫時不監控

把 "enabled" 設成 false，程式就會跳過它。
需要時把 false 改成 true、存檔，幾秒內就會開始監控。停用期間，之前已記錄的資料都會保留，重新啟用後會接著記錄。

排程設定：特定期間可更改抓取頻率（全域或商品底下都一樣）

"schedules": [
  { "dates": ["2026-10-07"], "start": "21:00", "end": "24:00", "interval_minutes": 1 }
]
日期的月、日要補零（2026-09-29，不是 2026-9-29）；"24:00" 代表午夜；多個時段用逗號隔開，多寫幾組 { }
